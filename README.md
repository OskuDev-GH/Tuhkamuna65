# Tuhkamuna65
GOTY in 1337

## Important info
This project's code is bad, do **not** use this project as an example of what to do.
I will **not** add compilation instructions for Windows or MacOS.

## Compilation:
Clone raylib: `git clone https://github.com/raysan5/raylib.git`
Follow the guide here to compile raylib: https://github.com/raysan5/raylib/wiki/Working-on-GNU-Linux
Run this command: `make`

## Running the game
Run this command in the build directory: `./tuhkamuna65`

## How to play
Try to get as many points as possible

### Controls
 - Start: S
 - Quit: Escape
 - Jump: Space
 - Pause: P
 - Restart (after death): R
